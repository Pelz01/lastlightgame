# Third-party notices

The project MIT license covers original Last Light code and artwork. It does not replace third-party licenses.

- **Barlow Condensed:** its SIL Open Font License is preserved in [design/runtime/FONT-LICENSE.txt](design/runtime/FONT-LICENSE.txt).
- **JavaScript packages:** NEAR Connect, NEAR JS libraries, cryptographic utilities, WebSocket support and build/test tools retain their distributed licenses. Versions are pinned by the project and design lockfiles.
- **Rust dependencies:** NEAR SDK and dependencies retain their licenses; versions are pinned in `contracts/last-light/Cargo.lock`.
- **Sandbox tooling:** the Linux test harness has a separate lockfile and is not bundled into the client.

Raster artwork was generated for Last Light; prompts and masters are in `design/`. Original SVG icons, wordmark and UI code are included. No Pinterest reference images are redistributed as game assets.
