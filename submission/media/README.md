# Demo images

These are actual screenshots captured from the hosted game through its normal controls. Each device has its own complete load → travel → sell sequence. Desktop uses 1366 × 900; phone uses a real responsive 390 × 844 viewport, with a full-page capture where needed.

For a desktop demo post, use `desktop-load.png`, `desktop-travel.png` and `desktop-delivery.png` in that order. For a phone-focused post, use the three `phone-` images. Do not present a phone capture as the desktop interface or vice versa. Each sequence ends after a successful oxygen delivery.

The images show untimed solo practice. They are not a claim that the screenshot actions were blockchain transactions. The separate completed online match is documented in [chain-proof.md](../chain-proof.md).

`capture.json` records the origin, capture time, dimensions, file hashes and actual result. Reproduce with `node scripts/prepare-demo.mjs`; this runs only browser-local solo actions and writes these images. Review the output before publishing it. Do not add personal submission fields or wallet credentials here.
