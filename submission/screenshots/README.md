# Seven screenshots — review set

Screenshot exports are saved locally in `Downloads/Last Light Screenshots`, not tracked in this repository. The ZIP and seven PNGs are there.

Seven unedited screenshots of the actual hosted game, all captured at **1366 × 900 desktop**. They are not phone screenshots stretched into desktop frames. The earlier desktop/phone set is in the local `Earlier desktop and phone` subfolder; [media notes](../media/README.md) describe it.

Images 1–4 and 7 come from one complete guided solo run. Images 5–6 show a separate solo market example: a real offer followed by Tess buying three oxygen for nine credits. No game state was seeded, balances edited or controls fabricated. Reduced motion was used to keep captures sharp.

These images show **solo practice**, not newly signed online transactions. The independently verified NEAR testnet results are linked in [chain-proof.md](../chain-proof.md). `capture.json` records the source, dimensions, hashes, captions and verified outcomes.
